# 🦷 CarePoint — Dental Clinic Appointment App
 
A cross-platform mobile app (React Native + Expo) for scheduling and managing dental appointments. Supports two roles: **Patients** who book appointments and **Doctors** who manage their schedule.
 
---
 
## 📱 Features
 
| Feature | Patient | Doctor |
|---|---|---|
| Login / Register | ✅ | ✅ (seeded only) |
| View Appointments | ✅ | ✅ |
| Book Appointment | ✅ | ✅ |
| Cancel / Edit | ✅ | ✅ |
| Home Dashboard | ✅ | ✅ |
| Dark Mode | ✅ | ✅ |
| Profile | ✅ | ✅ |

## 🚀 Getting Started
 
### Prerequisites
 
Make sure you have the following installed:
 
- [Node.js](https://nodejs.org/) (v18 or later)
- [Expo Go](https://expo.dev/go) app on your phone **or** an Android/iOS emulator
### Installation
 
```bash
# 1. Clone the repository
git clone https://github.com/ollymt/final-project-online-appointment.git
cd final-project-online-appointment
 
# 2. Install dependencies
npm install
 
# 3. Start the development server
npx expo start
```
 
### Running the App
 
After running `npx expo start`, a QR code will appear in the terminal.
 
| Platform | How to open |
|---|---|
| 📱 Android phone | Open **Expo Go** app → Scan QR code |
| 📱 iPhone | Open the **Camera** app → Scan QR code |
| 💻 Android Emulator | Press `a` in the terminal |
| 💻 iOS Simulator (Mac only) | Press `i` in the terminal |
| 🌐 Web browser | Press `w` in the terminal |
